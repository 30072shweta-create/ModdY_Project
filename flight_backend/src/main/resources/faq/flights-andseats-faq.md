# Flights and Seats - Frequently Asked Questions

## How can I search for flights?

You can search for flights by providing the source, destination, and travel date.

## What information is shown for a flight?

Flight information can include the airline, source, destination, departure time, arrival time, duration, price, and seat availability.

## Can I use filters while searching for flights?

Yes. Supported filters and sorting options can help users find suitable flights.

## How does seat selection work?

Users can select available seats during the booking process.

## Can I select a seat that is already booked?

No. A seat that has already been booked cannot be selected again.

## When can I select a seat?

Seat selection is available during the booking process for available seats.

## Can I see flight details before booking?

Yes. Flight information is available to help users select a suitable flight before proceeding with booking.
