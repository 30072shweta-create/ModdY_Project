# Flights and Seats

## Flight Search

Users can search for flights by providing:

* Source airport
* Destination airport
* Travel date

The system displays flights based on the search criteria.

Users can also use supported filters and sorting options to find suitable flights.

## Flight Information

Flight information includes details such as:

* Airline
* Source and destination
* Departure time
* Arrival time
* Duration
* Price
* Available seats

## Aircraft

Flights are associated with aircraft.

Aircraft information includes the aircraft model and seat capacity.

## Seat Selection

During the booking process, users can select available seats for passengers.

A seat that has already been booked cannot be selected again.

## Seat Availability

Seat availability depends on the current booking status.

The current availability of a particular seat is live information and will be retrieved from the system when required.
